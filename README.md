## 🛠️ Development Workflow

### Local Development
```bash
# Monorepo setup
npm run install:all
npm run dev              # Run both frontend & backend concurrently

# Backend only
npm run dev:backend

# Frontend only  
npm run frontend:dev
```

### Database Management
```bash
# Prisma migrations
npm run db:push          # Push schema to database

# PostGIS for spatial data
# Custom migrations for geo-data handling
```

### Deployment
```bash
# Vercel (Frontend)
vercel deploy

# Docker (Backend)
docker build -t app .
docker run -p 3001:3001 app
```
